# Vendor Payment Delay and Cash Flow Risk Analysis

## Project Overview

This project analyzes vendor payment delays and cash flow risks to help businesses understand payment patterns, identify overdue invoices, and forecast future cash outflows.

## Objectives

- Analyze vendor payment delays and overdue invoices.
- Identify late payment trends.
- Evaluate vendor-related cash flow risks.
- Forecast cash outflows for the next three months.
- Build an interactive dashboard for financial insights.

## Tools and Technologies

- **MySQL:** Data storage and SQL analysis
- **Python:** Data cleaning and analysis
- **Power BI:** Interactive dashboards and forecasting
- **Excel:** Data validation and preliminary analysis

## Key Performance Indicators (KPIs)

- Total invoice amount
- Total paid amount
- Outstanding payment amount
- Percentage of payments made late
- Monthly cash outflow
- Forecasted cash outflow

## Project Structure

- `sql/` — SQL queries and analysis
- `python/` — Python scripts
- `power-bi/` — Power BI dashboard
- `screenshots/` — Dashboard screenshots

## Business Value

This project helps finance teams monitor payment performance, identify potential cash flow problems, and improve short-term cash planning.
